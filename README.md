# Flutter СРС — Ибраимов Расул

| Папка | Работа |
|---|---|
| `srs1_flutter` | СРС 1 |
| `srs2` | СРС 2 |
| `srs2bezfoto` | СРС 2 (без фото) |
| `srs3` | СРС 3 |
| `srsp4` | СРСП 4 |
| `srsp5` | СРСП 5: форма регистрации + Firebase (Auth, Firestore) |
| `Srs6Flutter` | СРС 6: flutter_bloc, HTTP, JSON (список постов) |

Запуск любого проекта:

```
cd <папка>
flutter pub get
flutter run
```
